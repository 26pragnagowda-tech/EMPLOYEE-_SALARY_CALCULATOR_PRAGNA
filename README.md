# Employee Salary Calculator

## Project Description
The Employee Salary Calculator is a Python-based project
that calculates an employee's gross salary, deductions,
and net salary using configurable salary rules.

## Objectives
- Practice Python dictionaries and functions.
- Use conditional statements and loops.
- Implement salary calculation rules.
- Validate numeric inputs.
- Display a detailed salary slip.

## Features
- Calculate HRA and DA allowances.
- Calculate PF and tax deductions.
- Display gross and net salary.
- View sample employee records.
- Enter details for a new employee.
- Handle invalid salary inputs.
- Modify salary rules easily.

## Technologies Used
- Python 3
- Visual Studio Code

## Salary Calculation
Gross Salary = Basic Salary + HRA + DA

Total Deductions = PF + Tax

Net Salary = Gross Salary - Total Deductions

## How to Run
1. Install Python 3.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the command:

   python3 employee_salary_calculator.py
